# **Виджет банковских операций клиента**

## Описание: Это виджет, который показывает несколько последних успешных банковских операций клиента, сортирует по дате, фильтрует по операциям, маскирует номер карты и счета.

## Установка:

- Скачать zip file

	или

- Клонировать репозиторий:

```
git clone https://github.com/Vosstavshiyy/Skypro_DZ.git
```

## Использование:

>**Все функции запускаются через main.py**

```
python main.py
```

## Описание функций
### **Маскировка номера банковской карты и счета, вывод даты (src\widjet.py)**

---

1. Маскировка номера банковской карты:

Ввод:
```
mask_account_card('Visa Platinum 7000792289606361')
```

Вывод:
```
Visa Platinum 7000 79** **** 6361 
```

---

2. Маскировка счета:

Ввод:
```
mask_account_card('Счет 73654108430135874305')
```

Вывод:
```
Счет **4305
```

---

3. Форматирование даты в читаемый вид:

Ввод:
```
get_date('2024-03-11T02:26:18.671407')
```

Вывод:
```
11.03.2024
```

---

### **Фильтрация операций и сортировка даты (src\processing.py)**

Примеры ввода и вывода:

Входными данными будет следующий список словарей:

```
test_data = [
{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}
]
```

---

1. Фильтрация по значению ключа "state" (По умолчанию "EXECUTED")

Ввод:
```
filter_by_state(test_data)
```

Вывод:
```
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
```

---

Ввод:
```
filter_by_state(test_data, state='CANCELED')
```

Вывод:
```
[{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```

---

2.  Сортировка по "date" (по умолчанию — убывание)

Ввод:
```
sort_by_date(test_data)
```

Вывод:
```
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
```

---

Ввод:
```
sort_by_date(test_data, reverse=False)
```

Вывод:
```
[{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}]
```
